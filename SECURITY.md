# Security

This is experimental network audio software that includes a system audio plugin and a privileged clock service. No stable security-support lifecycle is offered yet.

For a suspected vulnerability, use **Security → Report a vulnerability** on GitHub when available. If private reporting is unavailable, open an issue asking for a private reporting channel without including sensitive details. Do not publish credentials, personal diagnostic archives or recordings.

Run test builds on a trusted local network. Keep source and dependency license notices when redistributing binaries, and distribute matching source for each release.
